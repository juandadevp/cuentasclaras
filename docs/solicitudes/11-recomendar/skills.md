# 11-recomendar: skills usadas

Módulo: **Recomendar compras**. Las skills están en `.claude/skills/`; el prompt y el plan de este módulo están en `prompt.md` y `plan.md` de esta carpeta.

| Skill | Para qué se usó en este módulo |
|---|---|
| `crear-pantalla-panel` | Pantalla «Recomendar compras» y «Resumen de la compra» al registrar el gasto. |
| `crear-accion-servidor` | Uso de la acción `buscarPrecios` con mensajes claros para cada error. |
| `integrar-api-externa` | Modo demostración sin clave y manejo de los errores del proveedor. |
| `escribir-pruebas` | Pruebas de la lógica de la compra y de la vista de resultados. |
| `vercel-react-best-practices` | Tarjetas de producto, filtros y orden calculados al renderizar, sin efectos. |
