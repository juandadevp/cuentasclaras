# 09-contacto-ayuda: skills usadas

Módulo: **Contacto y Ayuda**. Las skills están en `.claude/skills/`; el prompt y el plan de este módulo están en `prompt.md` y `plan.md` de esta carpeta.

| Skill | Para qué se usó en este módulo |
|---|---|
| `crear-migracion-supabase` | Tabla `mensajes_contacto`: cualquiera puede enviar un mensaje, nadie puede leerlos desde la app. |
| `crear-accion-servidor` | Acción de envío con validación en servidor y límite de un mensaje cada 20 segundos por correo. |
| `escribir-pruebas` | Pruebas de las validaciones y de los errores del formulario. |
| `vercel-react-best-practices` | Formulario de contacto y páginas como Server Components. |
