# 13-ahorro: skills usadas

Módulo: **Mi ahorro**. Las skills están en `.claude/skills/`; el prompt y el plan de este módulo están en `prompt.md` y `plan.md` de esta carpeta.

| Skill | Para qué se usó en este módulo |
|---|---|
| `crear-pantalla-panel` | Pantalla «Mi ahorro» con su enlace en el menú lateral, estados vacíos y avisos de error claros. |
| `escribir-pruebas` | Pruebas de la lógica pura del ahorro (`ahorro.test.ts`). |
| `vercel-react-best-practices` | Una sola consulta de gastos para todos los cálculos, consultas en paralelo y componentes de servidor sin efectos. |

No se usaron `crear-migracion-supabase` ni `crear-accion-servidor`: el módulo no crea tablas ni guarda datos.
