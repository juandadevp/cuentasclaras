# 06-presupuesto: skills usadas

Módulo: **Presupuesto mensual por categoría**. Las skills están en `.claude/skills/`; el prompt y el plan de este módulo están en `prompt.md` y `plan.md` de esta carpeta.

| Skill | Para qué se usó en este módulo |
|---|---|
| `crear-migracion-supabase` | Migración de `presupuestos`: un límite por usuario, categoría y mes, con seguridad por filas. |
| `crear-accion-servidor` | Acciones para fijar y quitar límites con validación y errores traducidos. |
| `crear-pantalla-panel` | Pantalla «Presupuesto» con resumen, tarjetas con barra de avance y navegación por mes. |
| `escribir-pruebas` | Pruebas de `progresoPresupuesto`, `ultimoMesPermitido`, `validarPresupuesto` y los errores. |
| `vercel-react-best-practices` | Componentes del formulario y de las tarjetas. |
