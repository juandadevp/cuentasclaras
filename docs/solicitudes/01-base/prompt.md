# 01-base: base visual y de configuración

Dejar lista la base visual y de configuración de Cuentas Claras, igual a la versión anterior (`legacy/v1`): layout raíz, tokens de color en `src/app/globals.css`, `src/config/site.ts` con las 12 categorías (tipo `Categoria` en `src/types/gasto.ts`), piezas de `src/components/ui` (`Campo`, `BotonOjo`, `ImagenDeFondo`) y utilidades `formatearMoneda` y `formatearFecha` en `src/lib`.

Restricciones: cuerpo blanco sin modo oscuro, logo intacto, Inter y Geist Mono con `next/font`, idioma `es`, textos en español, sin dependencias nuevas, sin inteligencia artificial. Skill usada: `vercel-react-best-practices`.
