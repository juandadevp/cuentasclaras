# 05-gastos: skills usadas

Módulo: **Gastos**. Las skills están en `.claude/skills/`; el prompt y el plan de este módulo están en `prompt.md` y `plan.md` de esta carpeta.

| Skill | Para qué se usó en este módulo |
|---|---|
| `crear-migracion-supabase` | Migración de la tabla `gastos` con restricciones, seguridad por filas e índice por usuario y fecha. |
| `crear-accion-servidor` | Acciones para crear, editar y eliminar gastos, con validación en servidor, sesión y errores traducidos. |
| `crear-pantalla-panel` | Pantallas «Registrar gasto», «Mis gastos» y «Editar gasto», con estados vacío y de error, y sus enlaces en el menú. |
| `escribir-pruebas` | Pruebas de las validaciones de gastos, los errores y los cálculos. |
| `vercel-react-best-practices` | Formulario con `key` para reiniciarse, listas por categoría y confirmación al eliminar. |
